# Ilustrações dos rankings

Ilustração exibida ao lado do título de cada ranking. Nome do arquivo = slug do ranking:

- `falou-merda.webp` (ou `.png` / `.avif`) — Troféu Falou Merda
- `sabio.webp`
- `bala-do-veio.webp`

Quadrada (ex.: 800×800) ou horizontal com fundo transparente (ex.: 1200×800); o formato é respeitado. O `npm run dev`/`npm run build` detecta os arquivos sozinho; sem arquivo, nada é exibido.
